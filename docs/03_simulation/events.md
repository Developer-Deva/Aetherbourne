# Event System
**Description:** Standardized event structure, historical logging, and emergent narrative chains for Aetherbourne
**Last Updated:** 2026-06-21
---

## Overview
Events are objective "facts" generated by the simulation. They represent the "what," "where," and "when" of the world's history, serving as the raw data from which subjective stories emerge.

---

## Event Structure
Every event is a modular payload containing:
*   **Category:** (Combat, Social, Environmental, Economic, etc.)
*   **Severity:** Objective impact (0-100).
*   **Scale:** Range of effect (Individual, Local, Regional, Global).
*   **Visibility:** Who can perceive the event (Private, Group, Public).
*   **Importance:** `Importance = Severity × Scale × WitnessCount`
*   **Actors & Targets:** The creatures, objects, or locations involved.

### Event Tags
Tags allow systems to react to broad event types:
*   `Combat`, `Family`, `Trade`, `Leadership`, `Discovery`, `Survival`, `Crime`, `Culture`.

---

## Event Outcomes
Outcomes are the **immediate, objective changes** to the state of the world or its inhabitants.
*   **Physical:** Health -10, Food +5, Resource Depleted.
*   **Social:** Relationship Points ±X, Territory Expanded, Status Changed.
*   **Biological:** Creature Dead, Offspring Born.

---

## Event Chains & Emergent Narrative
Events can trigger child events, creating complex "Story Pipelines" that are not authored, but emerge from systemic interaction.

**Example Chain:**
```text
Drought (Environmental)
↓
Crop Failure (Economic)
↓
Food Shortage (Survival)
↓
Migration (Social)
↓
Territory Conflict (Combat)
↓
War (Historical)
```

---

## The Story Pipeline
`Event → Subjective Interpretation → Emotional Response → Memory → Personality Drift`

---

## Design Philosophy
*   **Objectivity:** Events record data, not feelings.
*   **Modularity:** Any system (Weather, AI, Combat) can emit a standard Event payload.
*   **Persistence:** Events are permanent historical facts, even if the memories of them fade.
