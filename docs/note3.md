# Sprites

## Creature Sprites

The creature sprite system will be modular and layered. A creatures sprite will be based off of it's dna. There are going to be multiple interchangeable options for each part of the creature and each option will have an effect on their stats and/or survivablity in certain environment. 
There will be extensive modular categories including:

* Biped
